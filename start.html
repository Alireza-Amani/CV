📋 What's the difference?

  • Editable Version (index.editable.html) - Full editing capabilities with Vue.js, perfect for creating your own resume
  • Static Version (index.original.html) - Read-only preview, shows the original template design

🎯 Quick Start Guide

  • Open the editable version
  • Click the "✏️ Edit Mode" button
  • Click on any text to edit it
  • Use + Add buttons to add new items
  • Click "✓ Done Editing" when finished
  • Use Ctrl/Cmd + P to export as PDF
